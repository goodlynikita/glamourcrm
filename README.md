# GLAMOUR CRM

Интерактивный демопрототип. Для локального запуска выполните `python3 -m http.server 8000 --directory dist` и откройте `http://localhost:8000`.

Демопрофиль переключается в нижней части бокового меню. Фильтр филиала применяется ко всем разделам. Администратор открывает свою очередь задач, а руководитель может посмотреть всю команду и показатели по филиалам. Импорт выполняется в браузере с предпросмотром. Шаблон CSV можно скачать со страницы импорта.

Все встроенные записи синтетические. Задачи, загруженные клиенты и взаимодействия сохраняются в localStorage этого браузера. Демопрофили имитируют роли. Учётные записи и совместная синхронизация не настроены.

Рабочие сегменты определяются по дате последнего состоявшегося визита. Сегменты «45–89 дней», «90+ дней» и «Нет данных» включены в фильтр «Требуют внимания». Дата регистрации и дата будущей записи хранятся в отдельных полях. Даты рассчитываются по Москве.

## Подключение API «Малахита»

В `dist/repository.mjs` описана граница хранения с методами `read()` и `dispatch(command)`. `dist/model.mjs` определяет структуру снимка данных и операции изменения, а `dist/importer.mjs` переводит табличные строки в те же поля. Для подключения API понадобится серверный адаптер, который будет выдавать нормализованные данные и обрабатывать команды. В нём можно сопоставлять внешние идентификаторы клиентов и филиалов с внутренними идентификаторами и получать дату визита из завершённых посещений. Доступ и ключи API должны обрабатываться на сервере.
